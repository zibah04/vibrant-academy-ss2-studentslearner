# Teaching the Vibrant Academy SS2 Website

## Suggested three-week schedule

**Week 1 — HTML and teamwork**
- Find the page title, headings, paragraphs, links, and images.
- Give each student a chance to edit a short HTML block.
- Design, media, and writing teams prepare approved materials.

**Week 2 — CSS and integration**
- Practice selectors, classes, padding, margin, colors, fonts, borders, and grids.
- Build and edit student profile cards on the homepage.
- Recreate the circular portrait and magazine-style biography on individual story pages.

**Week 3 — Testing and presentation**
- Check every Read My Story link.
- Open the site on a desktop and a phone.
- Test navigation without JavaScript.
- Confirm consent and correct any spelling, image, or display problems.
- Have each student explain one HTML tag and one CSS rule they worked with.

## Easy exercises
1. Change a student's displayed hobby on the homepage.
2. Change their biography page heading and first paragraph.
3. Explain the difference between a rectangular homepage photo and a circular story photo.
4. Change a CSS color variable in `:root`.
5. Add a new profile card linking to a new `story-*.html` page.

## Teacher notes
This is a static website. Editing a page does not update other pages automatically. A database, user logins, and teacher approval would be a separate later project. Keep the original full-featured branch intact.
